# noblecloak-claude-agent-sdk-py

Approvals for the Claude Agent SDK (Python): every tool call is decided by NobleCloak before it runs, against the
same `/v1` module API contract as the other NobleCloak connectors. It builds on
[`noblecloak`](https://github.com/NobleCloak/noblecloak-py), the common Python library.

**Status:** reserved. The `0.0.0` release on PyPI holds the name and contains no code.
